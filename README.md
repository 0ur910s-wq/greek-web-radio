# GR Radio — Ελληνικό Web Radio

Μια στατική σελίδα HTML για ακρόαση ελληνικών ραδιοφωνικών σταθμών από browser. Δεν απαιτεί build ή backend: άνοιξε το `index.html` ή σέρβιρε τον φάκελο μέσω HTTPS.

## Λειτουργίες

- Αναζήτηση, κατηγορίες, αγαπημένα και προσθήκη δικών σου σταθμών.
- Αναπαραγωγή MP3/AAC και HLS μέσω HLS.js.
- Αυτόματη ενημέρωση του καταλόγου από το [Radio-Browser API](https://de1.api.radio-browser.info/).
- Ρολόι, καιρός Open-Meteo και επιλογή σκοτεινού/φωτεινού θέματος.

## Σημειώσεις

Τα stream URL ανήκουν στους αντίστοιχους ραδιοσταθμούς και μπορούν να αλλάξουν ή να περιοριστούν γεωγραφικά. Η εφαρμογή προτιμά HTTPS, επειδή οι σύγχρονοι browsers συνήθως αποκλείουν HTTP streams σε HTTPS σελίδες. Η κατάσταση ενός stream μπορεί να αλλάξει μετά τον έλεγχο· τα HTTP Range probes επιβεβαιώνουν ότι ο server απάντησε, όχι ότι ακούστηκε ο ήχος σε κάθε συσκευή ή browser.

Για τον καιρό, η σελίδα ζητά προαιρετικά γεωεντοπισμό και στέλνει συντεταγμένες στο Open-Meteo. Αν δεν δοθεί άδεια, χρησιμοποιεί την Αθήνα.

## Σημείο εκκίνησης

Άνοιξε το `index.html` σε σύγχρονο browser. Για πλήρη υποστήριξη ήχου/γεωεντοπισμού, χρησιμοποίησε HTTPS hosting. Τα Tailwind CSS, Font Awesome, Google Fonts και HLS.js φορτώνονται από εξωτερικά CDN.
